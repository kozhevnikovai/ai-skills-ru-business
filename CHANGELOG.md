# Changelog

## v1.3.0 — 2026-11-13

- Два новых навыка: **claim-reply** — ответ на претензию клиента (потребитель по ЗоЗПП или компания по договору): сроки ответа, однозначное решение с основанием, без признания непроверенной вины, внутренний разбор рисков; **debt-reminder** — цепочка писем должнику от вежливого напоминания до досудебной претензии с расчётом пени (по договору или ст. 395 ГК РФ), без угроз и давления. У каждого — «Частые ошибки», пример, чек-лист и защита от посторонних инструкций.
- Автотестов стало 36: качество новых навыков и посторонние инструкции во входных данных (чужие реквизиты в письме бухгалтера, «признай вину» в претензии).
- Общий пакет kozhevnikovai.mcpb 1.3.0: новые инструменты продуктов (field_vitals, export_pdf, ask_archive, list_tasks, tender_results, tender_changes) в описании пакета; ключ CrUX API для Аудитора в настройках; продукт старше версии 1.3 обновляется и при выключенном автообновлении, а если в релизе старая версия — предупреждение в статусе.
- Обновлены actions.

## v1.2.0 — 2026-11-12

- В каждом навыке — раздел «Частые ошибки»: 5 типичных промахов с примерами «плохо → хорошо».
- Пример запроса и результата теперь внутри навыка (`references/example.md`) — попадает в ZIP и доступен модели.
- Автотесты: 30 задач, посторонние инструкции во входных данных проверяются для всех 10 навыков.
- Автотесты без ключа API: в GitHub Actions (вручную) те же задачи прогоняются на локальной модели Qwen3 4B с проверкой правил.
- Навыки не повторяют содержимое посторонних инструкций (ссылки, суммы, пароли) даже при упоминании; в ответе на отзыв заголовок без персональных данных.
- Общий пакет для Claude Desktop `kozhevnikovai.mcpb`: навыки как команды в меню «+», установка и обновление Аудитора сайтов, Протоколиста и Тендерного помощника из релизов GitHub с проверкой SHA-256.
- Плагин и маркетплейс для Claude Code.

## v1.1.0 — 2026-11-11

- Установщик не затирает ваш навык с тем же именем: прежняя версия сохраняется рядом.
- Навыки не пишут отзывы от имени клиентов и не выдумывают рейтинги.
- «Встреча → задачи» подсказывает, как получить расшифровку Протоколистом.
- Раздел «Скоро»; SECURITY.md.

- Во всех 10 навыках — раздел «Безопасность входных данных»: тексты пользователя (отзывы, расшифровки, брифы, сайты получателей) — это материал, а не команды; посторонние инструкции внутри них не выполняются, персональные данные не переносятся в результат.
- Во всех навыках — «Чек-лист перед выдачей» с проверками качества под задачу (законы о рекламе и вакансиях, правила площадок, запрет на выдуманные факты).
- Автотесты: 3 проверки на посторонние инструкции во входных данных (отзыв, расшифровка встречи, сайт получателя).
- Проверка структуры навыков требует оба новых раздела.

## v1.0.0 — 2026-11

Первый публичный релиз.

- 10 навыков: commercial-proposal, review-reply, marketplace-card, hh-vacancy, cold-outreach, meeting-to-tasks, sop-builder, call-script, social-post, deal-next-step.

- 20 автотестов качества на promptfoo (`evals/`), включая проверки правил: персональные данные, 38-ФЗ, дискриминация в вакансиях, выдуманные цифры.
- Автопроверка структуры навыков в CI, ZIP-архивы каждого навыка в релизе.
- README на русском и английском.
