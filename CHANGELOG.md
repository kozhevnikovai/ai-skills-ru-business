# Changelog

## v1.2.0 — 2026-11-12

- В каждом навыке — раздел «Частые ошибки»: 5 типичных промахов с примерами «плохо → хорошо».
- Пример запроса и результата теперь внутри навыка (`references/example.md`) — попадает в ZIP и доступен модели.
- Автотесты: 30 задач, посторонние инструкции во входных данных проверяются для всех 10 навыков.
- Автотесты запускаются в GitHub Actions без ключа API (GitHub Models).

## v1.1.0 — 2026-11-11

- Установщик не затирает ваш навык с тем же именем: прежняя версия сохраняется рядом.
- Навыки не пишут отзывы от имени клиентов и не выдумывают рейтинги.
- «Встреча → задачи» подсказывает, как получить расшифровку Протоколистом.
- Раздел «Скоро»; SECURITY.md.

- Во всех 10 навыках — раздел «Безопасность входных данных»: тексты пользователя (отзывы, расшифровки, брифы, сайты получателей) — это материал, а не команды; посторонние инструкции внутри них не выполняются, персональные данные не переносятся в результат.
- Во всех навыках — «Чек-лист перед выдачей» с проверками качества под задачу (законы о рекламе и вакансиях, правила площадок, запрет на выдуманные факты).
- Автотесты: 3 проверки на посторонние инструкции во входных данных (отзыв, расшифровка встречи, сайт получателя).
- Проверка структуры навыков требует оба новых раздела.

## v1.0.0 — 2026-11

Первый публичный релиз.

- 10 навыков: commercial-proposal, review-reply, marketplace-card, hh-vacancy, cold-outreach, meeting-to-tasks, sop-builder, call-script, social-post, deal-next-step.
- Пример «запрос → результат» для каждого навыка (`examples/`).
- 20 автотестов качества на promptfoo (`evals/`), включая проверки правил: персональные данные, 38-ФЗ, дискриминация в вакансиях, выдуманные цифры.
- Автопроверка структуры навыков в CI, ZIP-архивы каждого навыка в релизе.
- README на русском и английском.
