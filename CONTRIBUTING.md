# Как предложить навык

1. Один навык = одна папка `skills/<name>/` с файлом `SKILL.md`.
2. `name` — латиница в нижнем регистре и дефисы, совпадает с именем папки.
3. `description` — на русском: что делает навык и **когда** его использовать (фразы, которыми пользователи формулируют задачу).
4. Внутри: входные данные → процесс → правила → формат ответа → самопроверка.
5. Навык не должен выдумывать факты, цены и кейсы; ссылки на законы — только проверенные.
6. Добавьте строку в таблицу в README и пример запроса.

Идеи без кода — в Issues (есть шаблоны). Перед PR запустите `python scripts/validate.py`.
