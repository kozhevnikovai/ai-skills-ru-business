# Скрипт звонка

Скрипт — не текст для зачитывания, а карта разговора: цель, ключевые фразы и ответы на типовые ситуации. Менеджер должен звучать как человек.

## 1. Входные данные

- Тип звонка: исходящий холодный / по заявке (тёплый) / входящий / повторный / возврат клиента / сервисный.
- Продукт и средний чек; кто клиент (B2B/B2C, роль ЛПР).
- **Цель звонка** — один следующий шаг (встреча, замер, счёт, визит, демо). Не «продать всё по телефону», если цикл длинный.
- Частые возражения, которые реально звучат (если знает пользователь).
- Конкурентные преимущества и доказательства (реальные).

## 2. Структура

1. **Приветствие и представление** — 1 фраза, имя + компания + повод звонка (для холодного — причина, почему звоним именно им).
2. **Разрешение** — «Удобно 2 минуты?» Если нет — договориться о времени.
3. **Квалификация** — 3–5 открытых вопросов о ситуации и задаче; для B2B — кто принимает решение и сроки.
4. **Связка** — пересказать задачу клиента его словами.
5. **Предложение** — 2–3 выгоды под озвученную задачу (не всё подряд).
6. **Возражения** — по схеме: согласиться с чувством → уточнить → аргумент/доказательство → вопрос на продолжение.
7. **Закрытие на шаг** — альтернативный выбор: «Удобнее во вторник утром или в среду после обеда?»
8. **Фиксация** — подтвердить договорённость, что отправим, когда созвонимся.

## 3. Возражения

Подготовь ответы минимум на: «Дорого», «Нам не нужно / уже есть поставщик», «Пришлите на почту», «Я подумаю», «Нет времени», «Надо посоветоваться» + специфичные из ввода. На каждое — 2 варианта ответа.

## 4. Правила

- Короткие реплики (до 2 предложений), вопросов больше, чем утверждений.
- Без давления, обмана и ложной срочности; уважать отказ.
- Исходящие рекламные звонки — только по законным основаниям (существующий клиент, согласие, деловой контакт); упомяни это пользователю, если речь о звонках по купленной базе (38-ФЗ, 152-ФЗ). Не юридическая консультация.

## 5. Формат ответа

1. Цель звонка и ключевая метрика.
2. Скрипт по блокам с репликами менеджера и вариантами ответов клиента (развилки).
3. Таблица возражений.
4. Чек-лист после звонка (что внести в CRM).
5. 3 типичные ошибки менеджера для этого звонка.
