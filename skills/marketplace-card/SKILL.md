# Карточка товара для маркетплейса

Карточка должна (1) находиться по запросам покупателя и (2) отвечать на вопросы до покупки, снижая возвраты.

## 1. Входные данные

- Площадка (Ozon / Wildberries / Яндекс Маркет / несколько).
- Товар: что это, бренд, модель, материал, размеры, вес, комплектация, страна производства, цвет/варианты.
- Для кого и в каких ситуациях используется.
- Отличия от конкурентов (реальные), сертификаты.
- Текущая карточка и частые вопросы/жалобы покупателей — если есть, это золото.
- Ключевые запросы — если у пользователя есть выгрузка из аналитики, используй её.

Не выдумывай характеристики, сертификаты, состав. Нет данных — `[уточнить: ...]`.

## 2. Ключевые запросы

Собери 3 группы и покажи пользователю:
- **Основной** — что это (напр. «термокружка»).
- **Уточняющие** — свойства/параметры («с крышкой», «500 мл», «нержавеющая сталь»).
- **Ситуационные** — для кого/куда («в машину», «подарок мужчине»).

Если реальных данных о частотности нет — честно отметь, что это гипотезы, и посоветуй проверить в аналитике площадки или Вордстате.

## 3. Название

Формула: **Тип товара + ключевое свойство + бренд/модель + параметр (объём/размер/цвет)**.
- Самый частотный запрос — в начале.
- Без капслока, восклицательных знаков, «хит», «лучший», «акция».
- Лимит длины и правила различаются по площадкам и меняются — напомни пользователю проверить актуальные требования в личном кабинете продавца.

## 4. Описание

1. Первый абзац (2–3 предложения) — что это и главная выгода, с основным запросом.
2. Блок выгод: 4–6 пунктов «свойство → польза».
3. Как пользоваться / уход / для кого подходит.
4. Комплектация.
5. Ответы на 2–3 частых вопроса (снимают возражения и возвраты).

Запросы — естественно, без переспама (каждый ключ 1–2 раза). Без контактов, ссылок, упоминаний других площадок и чужих брендов — это запрещено правилами маркетплейсов. Без медицинских обещаний и непроверяемых «лучший», «№1».

## 5. Характеристики и инфографика

- Таблица характеристик: заполни всё, что известно; пустые поля пометь.
- Тексты для 5–7 слайдов инфографики: на каждом слайде 1 мысль, заголовок до 4 слов + до 3 коротких буллетов. Порядок: главная выгода → ключевые свойства → размеры → комплектация → использование → доверие (гарантия/сертификат).

## 6. Формат ответа

1. Ключевые запросы (3 группы).
2. 3 варианта названия.
3. Описание.
4. Таблица характеристик.
5. Тексты слайдов.
6. «Уточнить перед публикацией» — список пробелов.
