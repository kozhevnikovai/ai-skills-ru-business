# Встреча → протокол и задачи

Ценность протокола — в том, чтобы через неделю было ясно: что решили, кто что делает и к какому сроку.

## 1. Входные данные

- Расшифровка, заметки или голосовое, переведённое в текст (любой беспорядок допустим).
- Дата встречи и участники с ролями — если не указаны, извлеки из текста.
- Куда пойдут задачи (трекер, таблица, мессенджер) — влияет на формат.

## 2. Как обрабатывать

1. Отдели **решения** (договорились) от **обсуждений** (мнения) — в протокол идут решения.
2. Каждую задачу формулируй как действие с результатом: глагол + объект + критерий готовности. «Подготовить КП для Альфа с 3 пакетами», а не «КП».
3. Ответственный — **один человек**. Если в тексте «мы/надо бы» без владельца — пометь `Ответственный: ❓` и вынеси в открытые вопросы.
4. Срок — дата. Относительные («к пятнице», «на следующей неделе») переведи в даты от даты встречи; если её нет — оставь как в тексте и пометь.
5. Не придумывай договорённостей, которых нет в тексте. Неоднозначное — в открытые вопросы с цитатой.
6. Цифры, суммы, даты, имена — переноси точно.

## 3. Формат ответа

```
# Протокол: <тема>, <дата>
Участники: …

## Ключевые решения
1. …

## Задачи
| # | Задача | Ответственный | Срок | Критерий готовности |

## Открытые вопросы / риски
- … (кто должен ответить)

## Следующая встреча
<дата/повод, если обсуждали>
```

Затем — **короткое письмо-резюме участникам** (до 150 слов): 3 главных решения + задачи по людям + «если что-то записано неверно — поправьте до <дата>».

Если пользователь указал трекер — дополнительно выдай задачи в виде CSV (`Задача;Ответственный;Срок`) для импорта.
